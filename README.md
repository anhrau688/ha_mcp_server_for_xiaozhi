# ha_mcp_server_for_xiaozhi
This component based on ha-mcp-for-xiaozhi repo v0.2.0 by c1pher-cn and added customs mcp services for climate device (example: hvac modes, fan modes, swing modes, preset modes) and Fan device (example: Oscillating mode, Direction modes). So you can via xiaozhi voice assist to control device in home assistant.
